# Joschat: Simple User Manual
**For everyday users and administrators**

## Start using Joschat
1. Open https://joschat.vercel.app/app.
2. Select **Create account** if new, or **Log in** if you already have an account.
3. Enter the requested details and follow the instructions.

## Chat with someone
1. Use the search box to find a username.
2. Select the person to open a chat.
3. Type your message and press **Send**.
4. To start a group, select **New group** and add usernames.

## Send a picture or file
Open a chat, use the attachment button, select an allowed file and send it. If the file is refused, check its size and type.

## Make a call
Open a direct conversation, then select the phone icon for a voice call or the video icon for a video call. Allow microphone/camera access when your browser asks. Use the hang-up button to finish.

## View call history
Select **Call history** in the chat area. You can see recent calls, their type, time and result. Use **Load more** for older entries.

## Use Joschat offline
Previously loaded parts of the application may remain available. Messages may queue while offline and send when the connection returns. Check that queued messages were delivered before leaving the app.

## Administrator access
If your account is an administrator, log in at /app and select **Admin** in the header. The dashboard is at https://joschat.vercel.app/admin. If access is refused, sign in again **in the same browser tab**.

## Common problems
- Can't log in? Check your credentials and connection, then try again.
- No sound or video? Allow permissions and verify network connection.
- Message won't send? Check the offline queue and retry.
- Can't open Admin? Only approved admin accounts can use it; contact platform support if your admin account is denied.

**Privacy:** Never share passwords, secret keys or verification codes.
